#### Single Event Effect (SEE) testing: Ion Beams

Centre for Accelerator Science

|                                |                                                                                                                                                                                                                                                                                                                                                                         |
|--------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Source Type                    | Protons beams                                                                                                                                                                                                                                                                                                                                                           |
|                                | Heavier ions beams                                                                                                                                                                                                                                                                                                                                                      |
| Energy spectrum                | Protons: up to 15 MeV                                                                                                                                                                                                                                                                                                                                                   |
|                                | Heavier ions: up to ~120MeV, depending on ion type                                                                                                                                                                                                                                                                                                                      |
| LET(Si)                        | Protons: 0.02 - 0.2 MeV.cm <sup>2</sup> /mg                                                                                                                                                                                                                                                                                                                             |
|                                | Heavier ions: 0.2 - 45 MeV.cm <sup>2</sup> /mg, depending on ion type                                                                                                                                                                                                                                                                                                   |
| Range(Si)                      | Protons: 15 - 2000 μm                                                                                                                                                                                                                                                                                                                                                   |
|                                | Heavier ions: 1 - 100 μm, depending on ion type                                                                                                                                                                                                                                                                                                                         |
| Flux                           | 10 <sup>4</sup> - 10 <sup>12</sup> particles/(cm <sup>2</sup> x s)                                                                                                                                                                                                                                                                                                      |
| Low rate regime                | 50 Hz - 50kHz                                                                                                                                                                                                                                                                                                                                                           |
| High current regime            | pA to μA                                                                                                                                                                                                                                                                                                                                                                |
| Features irradiation in vacuum | <ul style="list-style-type: none"><li>• Microbeam: focus spot down to 1μm</li><li>• Beam scanning or single spot irradiations</li><li>• Beam scanning area up to 3mm x 3mm</li><li>• Irradiation of decapsulated components</li><li>• Limited irradiation chamber: internal diameter 200mm, height 100mm</li><li>• Cable connection for real time measurement</li></ul> |

Features irradiation in ambient air

- Microbeam: focus spot down to 10µm
- Single spot irradiations in defocused mode also available
- Beam scanning area up to 3mm x 3mm
- Sample scanning area up to 50 mm x 50 mm
- Hybrid rapid scanning up to 50 mm x 50 mm
- Irradiation of bare components only
- Large irradiation enclosure: 280 x 380 x 230 mm<sup>3</sup> (XYZ)
- Cable connection for real time measurement.

#### Total Ionising Dose (TID) testing: Cobalt-60 Source

### Gamma Technology Research Irradiator (GATRI) facility

|                 |                                                                                                                                                                                                                                                                                                        |
|-----------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Source type     | Gamma-ray: Co-60 sources arranged on a rack of dimension approximately 1m <sup>2</sup> .                                                                                                                                                                                                               |
| Energy spectrum | 1.17 & 1.33 MeV                                                                                                                                                                                                                                                                                        |
| Dose rate       | ~ 0.01 - 0.22 Gy(Si)/s (or 1 -22 rad(Si)/s)                                                                                                                                                                                                                                                            |
| Field size      | Uniform planar field: 1m x 1m.                                                                                                                                                                                                                                                                         |
| Features        | <ul style="list-style-type: none"><li>• Irradiation of encapsulated and bare components.</li><li>• Irradiation of boards and larger systems, with shielding of selected areas.</li><li>• Large irradiation room (&gt;20 m<sup>3</sup>)</li><li>• Cable connection for real time measurement.</li></ul> |

#### Gammacell 220 Irradiator

|                                     |                                                                                                                                                                                                                                                                                                                           |
|-------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Source type                         | Gamma ray: Co-60 rods equally spaced in a stainless-steel rack to form a radioactive cylindrical shell of 20.9cm in diameter.                                                                                                                                                                                             |
| Energy spectrum                     | 1.17 & 1.33 MeV                                                                                                                                                                                                                                                                                                           |
| Dose rate                           | ~ 0.12 Gy(Si)/s (or 12 rad(Si)/s)                                                                                                                                                                                                                                                                                         |
| Field size                          | Isotropic cylindrical field: 15.2cm (diameter) x 20.6cm (height).                                                                                                                                                                                                                                                         |
| Features irradiation in ambient air | <ul style="list-style-type: none"><li>• Irradiation of encapsulated and bare components</li><li>• Irradiation of boards which fits the internal dimensions</li><li>• Limited irradiation room: internal diameter of 15.2cm and internal height of 20.6cm.</li><li>• Cable connection for real time measurement.</li></ul> |

#### Total Ionising Dose (TID) and Pre-screening: X-ray beams

## Australian Synchrotron

Source Type

|                                     |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|-------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|                                     | X-ray beam: Superconducting Multipole Wiggler on 3GeV electron storage ring                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Energy spectrum                     | 20 – 120 keV (monochromatic)                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Dose rate                           | ~ Gy(Si)/s to kGy(Si)/s (or ~tens of mrad(Si)/s to rad(Si)/s)                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Flux                                | $10^7 - 10^{14}$ photons/(cm <sup>2</sup> x s) (depending on energy)                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Features irradiation in ambient air | <ul style="list-style-type: none"> <li>• Collimated beam</li> <li>• Irradiated area from 100µm x100µm to 25mm x 100mm</li> <li>• Irradiation of incapsulated and bare components</li> <li>• High spot dose rate can provide pre-screening of components and mapping of sensitive areas</li> <li>• Large irradiation room</li> <li>• Cable connection for real time measurement.</li> <li>• Laminography for confirmation of the position and size of the die, and 3D imaging reconstruction</li> </ul> |
