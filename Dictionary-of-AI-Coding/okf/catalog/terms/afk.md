# Overview

AFK (away from keyboard) is a working pattern where an agent continues after the user has left. It can increase throughput through parallel unattended sessions, but early ambiguity can compound into coherent work aimed at the wrong outcome. Effective AFK work therefore benefits from clear specifications, automated checks, sandboxing, and reviewable outputs.

# Operational implication

Human review is deferred rather than removed. The unattended environment must provide enough constraints and feedback for the agent to fail safely and produce work that can be reviewed later.
