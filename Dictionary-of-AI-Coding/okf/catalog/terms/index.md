# AI Coding Term

* [AFK](afk.md) - An unattended work pattern in which a user starts an agent session and leaves it to continue without live supervision.
* [Attention budget](attention-budget.md) - The finite influence each token can distribute across the rest of a model's context.
* [Handoff artifact](handoff-artifact.md) - A durable document written by one session to carry relevant state into another session.
* [Model](model.md) - A stateless parameterized system that predicts output tokens from input tokens.
* [Model provider request](model-provider-request.md) - One round trip in which a harness sends context to a model provider and receives a response.
* [Output tokens](output-tokens.md) - Tokens generated by a model in its response, including visible text, tool calls, and reasoning output.
* [Permission request](permission-request.md) - A harness checkpoint that asks a user to approve a tool call that is not already authorized.
* [System prompt](system-prompt.md) - The standing instructions a harness places before user context in each model provider request.
* [Tool call](tool-call.md) - Structured model output that names a tool and arguments for the harness to validate and execute.
* [Turn](turn.md) - One user message and all agent activity that follows before control returns to the user.
